# Jason Achkar Diab Portfolio

Root-level Next.js App Router portfolio for https://www.jasonachkardiab.com.

## Stack

- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS 3

## Local Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Content

Canonical profile, project, experience, certification, and lab data lives in `content/`.
The three labs are client-side simulations using committed sample data only.

## Checks

```bash
npm run typecheck
npm run lint
npm run build
```
